# Conteúdo do Tropeiro

Fichas de emergência, guias e tabelas de consulta que o Tropeiro mostra e que a IA usa para responder, sem internet. Cada arquivo `.md` daqui vira uma página.

- **Quer contribuir?** Leia [CONTRIBUINDO.md](CONTRIBUINDO.md) e copie um dos [modelos](modelos/).
- **Temas:** [temas.yml](temas.yml).
- **Fontes oficiais:** [fontes.yml](fontes.yml). O servidor baixa cada documento da fonte oficial e guarda para consulta offline.

Para conferir se está tudo certo: `cd admin && npm run conteudo:validar`.
